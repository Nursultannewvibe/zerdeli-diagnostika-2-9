# Диагностика знаний 2–9 класс

Тесты и код для страниц Zerdeli в Webflow. Раздаётся через GitHub Pages,
подключается к страницам сайта тремя строками. Правки уезжают на сайт `git push`.

| Файл | Что это |
|---|---|
| `manifest.json` | список тестов: класс, предмет, сколько вопросов. Его читает лендинг |
| `tests.json` | все вопросы и правильные ответы, 19 тестов одним файлом |
| `images.json` | картинки формул, вложены прямо внутрь. Грузятся только если нужны тесту |
| `test.js` | движок теста вместе со стилями |
| `landing.js` | лендинг: разметка, стили и логика |

## Где это на сайте

| Страница Webflow | Файл |
|---|---|
| `/diagnostika-znaniy`, `/diagnostika-znaniy-kz` | `landing.js` |
| `/test`, `/test-kz` | `test.js` |

Язык берётся из адреса: слаг заканчивается на `-kz` → казахский.
Адреса теста: `/test` — список, `/test?class=5` — тесты класса,
`/test?test=5-matematika` — конкретный тест.

## Как поправить вопрос или ответ

Открыть `tests.json`, найти нужный тест по id, у вопроса поле `correct` —
номер верного варианта, **счёт с нуля**: первый вариант `0`, второй `1`.

```json
"n": 3,
"text": "Теңдеуді шеш: 4∙x+28=88 / Решите уравнение",
"options": ["12", "13", "14", "15"],
"correct": 3
```

Сохранить, закоммитить — через минуту на сайте.

Вопросы с полем `needsReview` движок **не показывает**: там при выгрузке из PDF
потерялась формула, подчёркивание или рисунок. Тест идёт без них.
